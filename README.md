# GitHub Workflow Practice

This repository is used to practice real-world GitHub collaboration workflows.

## Workflow

This project is used to practice a real-world GitHub workflow:

1. Create a feature branch
2. Make changes
3. Open a Pull Request
4. Review the changes
5. Fix review comments
6. Get approval
7. Merge the Pull Request

## Features

- Pull Requests
- Code Reviews
- Branching
- Merging
- Conflict Resolution
- Responsive navigation menu
